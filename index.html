Module 1 · 2 weeks · 8 sessions

Basic project management

The foundation for the two software modules. You learn how a project is defined, planned, costed, controlled and closed, and you practise each step on a case project of your own choosing. Agile project management is taught alongside the traditional approach.

What you gain

  • A clear picture of the project life cycle and the role of the project manager in each phase.
  • The ability to write a project charter, a scope statement and a work breakdown structure (WBS).
  • A working understanding of activity sequencing, durations and the critical path.
  • Skills to estimate cost, plan resources and build a baseline budget.
  • A method for identifying, scoring and responding to risk.
  • An understanding of Agile project management: Scrum, Kanban, user stories and sprint planning, and when to use Agile, predictive or hybrid approaches.
  • Tools to track progress and report variance using earned value basics.
  • A complete project plan for your capstone project, ready to reuse at work.

Prerequisites

  • No prior project management training is needed.
  • Comfort with a computer and basic spreadsheet use.
  • A real or imagined project (a building, an event, a product launch) to use as the capstone.

Module 2 · 1 week · 4 sessions

Microsoft Project tutorial

Hands-on training in building, resourcing, baselining and tracking a schedule in Microsoft Project. Every session ends with a practical exercise on one continuing case project.

What you gain

  • Confidence to set up a new project file with the right calendars and options.
  • The ability to build a task list, WBS and logic network with correct dependencies.
  • Skills to assign resources and costs and to spot over-allocation.
  • The habit of saving a baseline and updating progress to see schedule and cost variance.
  • Custom views, filters and reports you can send to a client or manager.

Prerequisites

  • Completion of Module 1, Basic project management. This is mandatory: Microsoft Project training is not taken on its own.
  • A Windows laptop with Microsoft Project installed (Project Standard, Professional or a Project Plan subscription).
  • Working knowledge of Microsoft Excel or similar office software.

Curriculum

Module 3 · 1 week · 4 sessions

Primavera P6 training

Practical training in Oracle Primavera P6 Professional, the scheduling tool used on large construction, oil and gas and infrastructure projects. You build a multi-level schedule, resource-load it and update it against a baseline.

What you gain

  • Understanding of how P6 organises work: enterprise project structure (EPS), organisational breakdown structure (OBS) and projects.
  • Skills to build a WBS and activity network with all relationship types, lags and constraints.
  • The ability to schedule, read float and identify the critical path.
  • Resource and cost loading, and comparison of planned against actual.
  • Baseline creation, progress updating and clear layouts and reports for project meetings.

Prerequisites

  • Completion of Module 1 (Basic project management) and Module 2 (Microsoft Project). Both are mandatory before Primavera P6.
  • A Windows laptop with P6 Professional installed, or access to a training installation. We can advise on the setup before the first session.
  • Working knowledge of Microsoft Project from Module 2, because Primavera builds on the same scheduling logic.
